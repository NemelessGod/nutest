# Аудит перед JOKER’S ABYSS 2.0

## Фактическая база и решение

Исходная точка: Git `ad9875a` (NEON SERPENTS 1.0). В репозитории нет покерного scoring engine, карточных сохранений, джокеров, блайндов, магазина карт или Ante. Количество определённых / работающих покерных джокеров до изменений: **0 / 0**. Поэтому восстановление несуществующей прежней карточной реализации невозможно. После уточнения пользователя используем этот репозиторий, добавляем карточные системы, сохраняя существующую игру по отдельному адресу.

## Приоритеты

- **P0:** требуемый карточный игровой цикл отсутствует. Нужны раздача, игра/сброс, блайнды, магазин, следующий Ante, победа/поражение/бесконечный режим.
- **P1:** отсутствуют покерные правила, big-number scoring, порядок эффектов, копирование/повторы, проклятия и боссовые ограничения. Требуется чистое тестируемое ядро.
- **P1:** нет карточных сохранений. Добавляется отдельное версионированное хранилище с валидацией, резервной копией, импортом/экспортом; существующая SQLite не меняется. Миграцию неизвестного стороннего формата нельзя объявить проверенной без примеров.
- **P2:** текущий интерфейс рассчитан на Canvas-змейку, не на карты. Новый стол и меню получают отдельные CSS, ввод и эффекты, не вмешиваясь в сетевую игру.
- **P2:** нужны измеримые симуляции баланса и отдельные мобильные E2E вместо обещаний производительности устройств.
- **P3:** оригинальная SVG-графика, звук, анимации, коллекция, доступность и dev-панель.

## Что сохраняем

Авторитетный Node/Socket.IO сервер, все классы/способности/режимы/боты/события NEON SERPENTS, SQLite-аккаунты и результаты, API, Windows launcher, Docker, существующие тесты. Старый интерфейс доступен на `/serpents.html`. Главная страница становится карточной игрой. Данные `data/neon.sqlite` не удаляются и не мигрируются в карточный формат.

## Архитектура расширения

TypeScript-модули внутри существующего Vite-клиента; детерминированный PRNG; Decimal для счёта; раздельные каталоги, покер, scoring, run-state, сохранения, UI/аудио. Карточная игра одиночная и может работать без сетевого аккаунта; её прогресс локальный, экспортируемый. Сетевой PvP по-прежнему рассчитывается сервером.

## Базовая проверка

Перед изменениями: 19/19 серверных и интеграционных тестов проходят, production-сборка Vite успешна. Существующие E2E будут привязаны к старому маршруту и дополнены карточными проверками. Точка отката — Git tag `pre-abyss-2.0`. Физические Windows/Android и Firefox в этой среде недоступны.
