# Проверка джокеров 2.0

В исходном репозитории карточных джокеров: 0. В 2.0 определено 36, из них 20 эволюционируют. Для каждого есть отдельная проверка наблюдаемого scoring/event/rule-эффекта в `tests/abyss/release.test.ts`; дополнительные тесты проверяют порядок, копии, циклы, деньги и персистентность эволюций. Это проверка реализации, а не заявление о равной силе всех стратегий.

Базовые вероятности обычного магазинного джокера: 65% / 25% / 9% / 1%. Это вероятности каждого отдельного предложения, не гарантия на конкретный забег. Специальный Summoner создаёт только common. Повторные экземпляры разрешены; Echo суммирует повторы с общим пределом, Astronomer даёт +1 уровень за каждый экземпляр, Bank суммирует лимиты процентов. Four Fingers — булево правило, два экземпляра не снижают требование до трёх карт.
