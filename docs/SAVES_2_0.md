# Сохранения 2.0

Ключ: `jokers-abyss.save.v2`. Резервная копия: тот же ключ + `.backup`. Данные NEON SERPENTS в SQLite и старые localStorage-ключи не изменяются.

Формат JSON: `{ "version": 2, "payload": "<JSON {run, profile}>", "checksum": "<FNV-1a hex>" }`. Checksum нужен для случайных повреждений, не для защиты одиночной игры от редактирования. Импорт ограничен 2 MB и проверяет версию, типы, конечность очков, уникальные карты/зоны, известные каталоги, параметры, журналы, статистику и настройки до замены состояния.

Каждое изменение сохраняет текущую валидную копию как backup. Если оригинал повреждён, он сохраняется под `.corrupt.<timestamp>`, затем записывается новый файл. Ни один ключ не удаляется автоматически. При ошибке записи/квоте пользователь получает сообщение и может экспортировать текущий прогресс. При повреждённом основном файле читается backup; если обе копии повреждены, игра продолжает в памяти и предупреждает об этом. Подтверждённый валидный импорт восстанавливает постоянное хранилище и сохраняет повреждённый оригинал для диагностики.

Собственный минимальный формат v1: `{ "version": 1, "seed": "..." }`, либо `{ "version": 1, "run": {...}, "profile": {...} }` с полями нашего ядра. Миграция добавляет дефолты v2 и валидирует результат. Формат неизвестной сторонней игры не угадывается: исходный репозиторий не содержал покерных сохранений. Неизвестные версии отклоняются, прежние данные остаются на месте.

LocalStorage привязан к origin: смена http/https, домена или порта означает отдельное хранилище. Для переноса между ПК и телефоном используйте экспорт/импорт JSON. Автоматической сетевой синхронизации одиночной игры нет. Запуск одного карточного профиля в нескольких вкладках не поддерживает слияние изменений: используйте одну активную вкладку.
