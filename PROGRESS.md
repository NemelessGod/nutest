Фазы A–F завершены в текущей облачной среде. Корневая страница — карточный roguelike; NEON SERPENTS и её сервер/SQLite сохранены на /serpents.html. Исходная точка — tag pre-abyss-2.0, аудит содержит фактические причины добавления карточного ядра.

Реализованы 36 уникальных джокеров (20 эволюций), 12 комбинаций, Decimal scoring с журналом, четырёхкарточные правила/печати/улучшения/издания, четыре проклятия, энергия, цепочки, добровольные аномалии, 11 боссов, три блайнда × восемь Ante и endless. Магазин продаёт джокеры/планеты/11 Таро/пять спектров/бустеры/ваучеры/проклятые карты. Пять колод, четыре сложности, 15 испытаний, 32 достижения, статистика и коллекция получают реальные состояния.

Добавлены собственная SVG-графика, адаптивное меню/стол, мышь и touch, сортировка/перетаскивание/long press, четыре скорости, ограниченные частицы, звуковые категории, доступность, fullscreen и dev-only диагностика. Карточные сохранения имеют backup/checksum/валидацию/импорт/экспорт/миграцию собственного v1; старые данные не удаляются.

Проверено: npm ci, typecheck, production build; 114/114 тестов, 18/18 браузерных сценариев, 200 симуляций (186 побед, 0 ошибок), прохождение всех 15 испытаний. Docker build/runtime и обе страницы проверены. Подробности и пределы доказательств — docs/RELEASE_2_0.md; исходные результаты — docs/simulation-2.0.json.

Облачные install_script/start_skill обновлены и сохранены в draft. Публикация snapshot выполняется пользователем в настройках среды. Сайт публично не развёрнут; реальные Windows/Android/Firefox и человеческий баланс требуют ручной проверки. Прогресс одиночной игры локален и переносится JSON; сетевые аккаунты змейки по-прежнему в SQLite.

## История NEON SERPENTS (сохранена)

# Состояние проекта

Реализованы клиент Canvas/Vite и авторитетный сервер Express/Socket.IO, 30 Hz симуляция, пространственная сетка, PvP-комнаты, 40 AI с шестью моделями, три класса, пять способностей, три режима, пять событий и трёхфазный босс.

Реализованы неоновое меню, гараж, задания, 17 достижений, рекорды, HUD, TOP-10, minimap, экран смерти/повторный вход, процедурные эффекты/звук, настройки качества/FPS, переназначение клавиш, мультитач/джойстик и fullscreen.

SQLite хранит гостей, зарегистрированные аккаунты (scrypt), хешированные сессии, серверные награды/статистику, косметику и настройки. Клиент не задаёт результаты/валюту. Повторный вход и восстановление SQLite проверены.

Проверено:

- Чистая `npm ci`, `npm run build`, `npm test`: 19/19.
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`: 6/6 (desktop + Android emulation).
- Два независимых сетевых клиента видят друг друга; две браузерные сессии заходят в общую комнату.
- Настоящий мультитач через Chromium CDP: джойстик + ускорение одновременно.
- `npm run dev`: Vite + сервер, health/API через прокси, браузер без pageerror.
- `npm audit --omit=dev`: 0 известных уязвимостей на момент проверки.
- Профиль 40 ботов / 1800 шагов: mean ~1.52 ms, p95 ~3.15 ms, max ~16.91 ms в этой среде. Это серверный замер, не Android FPS; случайный мир меняет результаты.

Исправлены найденные ошибки: сброс несохранённого ника при выборе скина, мгновенное повторное столкновение после щита, небезопасное размещение возле границы, размер передаваемых координат, работа камеры при входе.

Конфигурация облачной среды: install_script (npm ci + build) и start_skill (перезапуск dev/production и проверки) сохранены в draft. Публикацию выполняет пользователь через настройки среды. Dev-процесс может быть остановлен после снапшота; его нужно перезапустить.

Оставшиеся ограничения:

- Публичный HTTPS-хост и домен ещё не предоставлены/не опубликованы; инструкции, Docker и Caddy готовы.
- Физические Windows 10/Android и Firefox не проверялись; есть инструкция ручной проверки.
- Reconnect начинает новый полёт после сохранения оборванного матча, не восстанавливает старую змею.
- PostgreSQL-адаптер и кластер серверов — дальнейшее развитие; текущий production использует один процесс + SQLite на постоянном диске.

Docker-сборка и runtime успешно проверены: HTML + health + два настоящих Socket.IO-клиента в одной комнате. Исправлены права COPY для работы под непривилегированным пользователем node (в облачной среде исходники имели 0600/0700). Smoke-контейнер и его временный том удалены после проверки.

Диагностика Docker: облачный сетевой proxy требует передачи стандартных proxy build args и временного CA через BuildKit secret, без отключения TLS и без сохранения сертификата в образе.

E2E перенесён на отдельный порт 3010 и системную временную SQLite; повторная проверка 6/6 прошла одновременно с работающим dev-сервером. Файлы проекта отформатированы; formatter check и git diff --check прошли. ZIP включает исходники и dist, но исключает базы, cookies, .env, Git и node_modules.

Исправление запуска Windows по скриншоту пользователя: START_WINDOWS.bat переведён в ASCII + реальные CRLF, которые Git сохраняет через .gitattributes. Добавлены проверки Node/npm/версии, стандартной папки установки и понятные выходы при ошибках. Проверены байты файла и Git whitespace check; выполнение на физической Windows пока не проверено.
